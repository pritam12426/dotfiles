## INSTALLATION

```sh
mkdir -p "$HOME/Developer/git_repository"
cd "$HOME/Developer/git_repository"

# Change the https origin to ssh url with git command
git clone "https://github.com/pritam12426/dotfile.git" dotfiles

cd dotfiles/dirwin
export DOT_FILE="$PWD"
./install.zsh
```
